# Source notes

AI-generated images and instructions. Errors possible.

The STL meshes are mounting plates. They are rendered without changing their geometry. Overall sizes are measured from mesh bounds in millimetres. Board sizes and MD5 alpha codes come from working.yaml. The board record code does not identify a printed plate.

No electronic board, wire holder or unspecified fastener is added to the scene. The printed variants are alternatives. Board fastening, electrical wiring, print settings and physical fit are not inferred from a render.

Full source metadata remains in working.yaml; the README is the shortened public pass. Use presentation/config.json for reviewed titles, hardware, installation actions and source links. Rebuild from this folder with `oobb-present`.
